Este projeto tem como objetivo desenvolver uma aplicação Delphi Mobile para auxiliar na procura de lares definitivos e temporários para 
animais em situação de rua.
A aplicação conta com funcionalidades de login, cadastro dos animais, cadastro do adotante, cadastro do interessado em disponibilizar 
moradia temporária ao pet e envio de pedidos de adoção e hospedagem ao usuário que cadastrou o pet na aplicação (podendo ele aceitar
ou não a solicitação).
O projeto foi desenvolvido como trabalho final do curso de Análise e Desenvolvimento de Sistemas com foco em resolver problemas reais da 
comunidade.
